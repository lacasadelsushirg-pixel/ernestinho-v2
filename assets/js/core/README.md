# Ernestinho Core — Fase 4 B1

Pure modules for the canonical data layer.

Rules:
- No DOM/presentation code here.
- No live network calls here.
- ENTITY, OCCURRENCE and SIGNAL are separate concepts.
- UNKNOWN is never treated as safe/current.
- One physical entity may have multiple editorial views.
- Localized prose lives outside canonical neutral data.
- Sources/provenance travel with volatile facts.
- Premium route sequence/navigation/timing is not stored in public guide records.

This layer is additive and does not replace existing runtime until migrated and validated.
