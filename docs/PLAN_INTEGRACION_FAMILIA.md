- BioParque: se cuentan las tomas restantes de bote y recinto, pero no se insertan porque repiten escenas ya cubiertas o no mejoran la historia.
- AquaRio, Catacumba, Planetario, Barra Bowling y Escape 60: las fotos extra son repetidas, carteles o encuadres con menor valor que las seleccionadas.
- Parque Lage: las cinco fotos HEIC restantes existen. Se dejan sin usar por repetición o poca utilidad distinta; el sitio no publica HEIC directamente.
